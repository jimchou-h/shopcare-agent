# server-deepseek Specification

## Purpose

在公开预置演示保持零 Key 的前提下，让受控实例由服务端调用 DeepSeek，基于有限政策证据生成可核查的回答，并在上游异常时降级或保留重试。

## Requirements
### Requirement: 部署者控制模型模式及凭证

系统 SHALL 默认提供无 Key 的预置问答。真实模式 MUST 由部署者通过服务端运行时配置启用。部署者 Key MUST 仅用于服务端直达 DeepSeek 官方 HTTPS API 的鉴权，浏览器、对外响应、日志和构建产物 MUST 排除该 Key。

#### Scenario: 公开演示默认使用预置

- **WHEN** 实例以默认配置启动，访客打开页面问「换货期限是多久？」
- **THEN** 页面经同源问答接口显示既有政策正文和出处
- **AND** 本轮标明预置，服务端不发模型请求

#### Scenario: 迁移后浏览器清理旧 Key

- **WHEN** 曾使用旧版的浏览器加载新版页面，且同源存储仍有旧版 DeepSeek Key
- **THEN** 页面删除旧存储项，并通过一个同源问答接口提交问题
- **AND** 页面没有 Key 输入、保存或启用凭证入口

#### Scenario: 真实模式缺少部署凭证

- **WHEN** 部署者启用真实模式但 Key 缺失或只包含空白
- **THEN** 服务端报告缺失配置项，错误内容排除 Key

### Requirement: 使用政策证据生成可核查的回答

在真实模式下，系统 SHALL 以服务端给定的政策证据向 DeepSeek 请求一轮生成。展示生成正文前，系统 MUST 校验结果结构、候选身份、引用和可核查的政策事实。页面 MUST 标明本轮实际使用的回答来源。

#### Scenario: 真模型根据确定的政策生成正文

- **WHEN** 受控实例开启真实模式，顾客问「换货期限是多久？」且 DeepSeek 返回校验通过的生成结果
- **THEN** 页面显示生成正文并标明「DeepSeek 生成」
- **AND** 出处标题和摘录来自支撑该答案的换货期限条目，服务端请求 Key 仅出现在官方鉴权头

#### Scenario: 能确定主题的新问法或否定疑问句

- **WHEN** 顾客提交「换货最晚什么时候能办？」「我不能换货吗？」或「不是不能换货吧？」，已有关键词未命中且模型选中能支持问题的候选
- **THEN** 页面展示校验通过的生成正文和对应政策出处

#### Scenario: 证据不足或生成与依据不一致

- **WHEN** 提问主题不清、已有证据歧义、模型拒配，或模型给出越界 ID、错误引文或与摘录冲突的政策结论
- **THEN** 页面引导补充信息，或在现有检索能独立确认政策时展示有出处的预置降级答复
- **AND** 相关错误结论不会被展示为模型生成答复，已知歧义和主题不明时不发模型请求

#### Scenario: 否定后转向无关主题

- **WHEN** 顾客问「我不想换货，会员积分兑换需要什么条件？」
- **THEN** 页面提示补充信息，本轮不调用模型或展示换货政策

### Requirement: 上游异常后保留问答可用性

系统 SHALL 给出受控的错误或降级反馈。可重试失败 MUST 保留实际提交的问题和当前输入草稿。

#### Scenario: 可信的预置答复可降级

- **WHEN** 模型鉴权失败、额度受限、上游超时或响应格式异常，且现有检索能明确回答本轮问题
- **THEN** 页面显示预置答复和出处，并标注本轮降级
- **AND** 页面错误或说明中不包含上游原始响应或凭证

#### Scenario: 无法降级时重试原问题

- **WHEN** 上游故障且现有检索无法独立回答，期间顾客修改了输入草稿
- **THEN** 失败卡片显示实际提交的问题和可理解的错误提示
- **AND** 重试重新发送卡片中的原问题，输入框保留新草稿
