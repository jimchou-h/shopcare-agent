## 1. 查单与补问

- [x] 1.1 访客在问答页领取并查询自己的示例订单（React 领取入口和状态卡片、Fastify 问答分发、会话 Cookie、SQLite 迁移和订单归属查询）。验收结果含单号、商品和已签收状态，重复领取复用订单，无会话时有领取引导，其他访客单号与未知单号响应一致，跨来源领取失败。普通 FAQ 可用，查单和混有演示单号的政策提问不触发模型。
- [ ] 1.2 顾客在下一轮补充单号完成查询（服务端识别明确查单、SQLite 待补状态和页面提示）。验收「查订单」后只发单号得到状态，格式错误或找不到时可以修正，切换到 FAQ 或打开独立会话时不会沿用待补状态，跨来源请求无法更改待补状态。依赖 1.1。

## 2. 容器恢复

- [ ] 2.1 部署后可以在容器重建时恢复查单（SQLite 数据卷、自动迁移、容器冒烟和启动说明）。验收无 Key 的干净环境可演示查单，保留数据卷重建后原浏览器继续补单号并查询同一订单，独立会话仍隔离，过期凭证得到重新领取引导。依赖 1.2。
