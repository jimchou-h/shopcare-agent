## 1. 换货资格与提交

- [x] 1.1 顾客在自己的订单卡片上核对换货资格并预览摘要（React 表单、Fastify 资格用例、签收时间迁移与 FAQ 出处）。验收支持迁移前已有的演示订单，合格时显示确认摘要和两类运费说明，第 7 天可申请、第 8 天提示逾期，未签收或商品条件不满足时显示对应原因，访客之间隔离且全过程无需模型。
- [ ] 1.2 顾客明确确认后提交一笔换货申请（确认按钮、服务端同源与归属检查、资格复核、SQLite 幂等事务）。验收有效确认返回申请编号与「已提交」，同一确认重复和并发返回同一编号，过期或被替换的摘要、资格变化、跨来源以及其他访客的确认都无法创建申请。依赖 1.1。

## 2. 申请结果恢复

- [ ] 2.1 顾客在响应中断后恢复申请结果（页面重试、订单卡片回执、Docker 数据卷冒烟）。验收服务端已写入但响应丢失时重试原确认得到同一编号，刷新与容器重建后原会话查单可以看到原申请，独立会话看不到其他访客的申请。依赖 1.2。
